# ごみ分別クイズ

まちがえやすい「ごみ分別あるある」に挑戦する2〜3択クイズです。回答後に豆知識を表示し、最後まで解くと修了証（PNG画像）を発行できます。GitHub Pagesでそのまま公開できる静的サイトです。

## ファイル構成

```
index.html          クイズ本体（利用者が見るページ）
board.html           修了証の獲得者一覧・連続正解ランキング
admin.html           管理者画面（パスワード付き。問題の編集・ランキングの管理）
css/style.css         共通デザイン
css/admin.css         管理者画面用デザイン
js/quiz.js            クイズの動作
js/admin.js           管理者画面の動作（問題の編集）
js/admin-gate.js      管理者画面のパスワード画面
js/admin-board.js     ランキング・獲得者の名前変更／削除
js/certificate.js     修了証（PNG）の生成
js/firebase-config.js Firebaseの接続設定（★自分の値に書き換える）
js/firebase-service.js Firestoreへの保存・取得
js/board.js           board.htmlの表示処理
firestore.rules       Firestoreのセキュリティルール（コンソールに貼り付ける）
data/questions.json   問題データ本体（★ここを編集すればサイトの内容が変わります）
images/               イラスト素材（SVG）
```

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作成します（例: `gomi-quiz`）。
2. このフォルダの中身をすべてそのリポジトリの直下にアップロード（コミット）します。
   - GitHub Desktopや `git` コマンドでも、GitHubの「Add file → Upload files」からでも構いません。
3. リポジトリの **Settings → Pages** を開きます。
4. 「Source」で `Deploy from a branch` を選び、ブランチを `main`、フォルダを `/root` に設定して保存します。
5. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` でサイトが公開されます。
6. 管理者画面は `https://（ユーザー名）.github.io/（リポジトリ名）/admin.html` です。

## 問題・画像・豆知識の変更方法（管理者画面）

コードを触らずに、ブラウザ上の管理者画面 `admin.html` から編集できます。

1. `admin.html` をブラウザで開きます（公開後のURL、またはパソコン内のファイルを直接ダブルクリックでもおおむね動作します）。
2. 各問題カードで以下を編集できます。
   - **問題文**：テキストを直接編集
   - **画像・イラスト**：
     - `images/xxx.svg` のようなパスや、画像の URL を直接入力する
     - または「ファイルを選択」から手持ちの写真・イラストをアップロードする（自動的に問題データに埋め込まれます）
   - **選択肢**：2〜3個まで。ラジオボタンで正解を指定します
   - **豆知識**：回答後に表示される文章
3. 「＋ 新しい問題を追加」で問題を増やせます。カード右上の「削除」で問題を削除できます。
4. 上部の「サイト全体の設定」からタイトル・サブタイトル・修了証のタイトル/メッセージ/合格ラインを変更できます。
5. 「プレビューをサイトで見る」で、編集中の内容をこのブラウザ内ですぐに確認できます（自動的にこのブラウザに一時保存されています）。
6. 編集が終わったら **「JSONをエクスポート」** ボタンを押して `questions.json` をダウンロードします。
7. ダウンロードした `questions.json` を、GitHubリポジトリの `data/questions.json` に上書きアップロードします（GitHub上で該当ファイルを開き、鉛筆アイコンや「Upload files」から置き換え → Commit）。
8. 数十秒〜数分でサイトに反映されます。

### 画像をアップロードする場合の注意

「ファイルを選択」で画像を取り込むと、画像データがJSONファイルの中に直接埋め込まれます（手軽ですが、JSONファイルが大きくなります）。
大きな写真をたくさん使う場合は、あらかじめ画像を軽量化した上で `images/` フォルダにアップロードし、パス入力欄に `images/ファイル名.jpg` のように入力する方法をおすすめします。

### 他のパソコン・ブラウザで編集を引き継ぎたいとき

管理者画面の編集内容はブラウザ内に自動保存されますが、別のパソコンやブラウザには引き継がれません。
「JSONをエクスポート」でダウンロードした `questions.json` を、別の環境の管理者画面で「JSONを読み込む」から読み込めば、続きを編集できます。

## ローカルで動作確認する場合

`index.html` を直接ダブルクリックして開くと、ブラウザの制限で `data/questions.json` を読み込めないことがあります。その場合は、フォルダ内で簡易サーバーを立てて確認してください。

```
# フォルダのルートで実行
python3 -m http.server 8000
```

その後ブラウザで `http://localhost:8000/` を開きます。

## 注意事項

- 分別ルールは自治体によって異なります。サイト内にも注記していますが、実際の運用（学校・自治体等での配布）に使う際は内容の最終確認をお願いします。
- イラストはすべてこのプロジェクト用に作成したオリジナルのSVGです。実際の商品写真などに差し替えたい場合は、著作権に配慮したうえで管理者画面からアップロードしてください。

## 獲得者一覧・連続正解ランキング（Firebase）の設定

修了証を獲得した人の一覧と、連続正解数のランキングを `board.html` に表示します。データの保存先には Firebase の Firestore（無料のSparkプランで利用可能）を使います。
**設定しない場合でもクイズ本体は通常どおり動きます**（この2機能だけが無効になります）。

### 1. Firebaseプロジェクトを作る
1. https://console.firebase.google.com/ で「プロジェクトを追加」。Googleアナリティクスはオフで構いません。
2. 左メニュー「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）がおすすめ。モードは**本番環境モード**を選びます。

### 2. セキュリティルールを設定する
1. Firestore Database の「ルール」タブを開きます。
2. このフォルダの `firestore.rules` の中身をすべて貼り付けて「公開」します。
   - 誰でも閲覧でき、新規追加は形式チェック付きで許可、**名前の変更・削除は管理者アカウントでログインした場合のみ**許可、という内容です。
   - 管理者アカウントのメールアドレス（`admin@gomi-quiz.example.com`）は、`firestore.rules` と `js/firebase-config.js` の両方に書かれています。変えるときは必ず両方を同じにしてください。

### 3. Webアプリを登録して設定値を貼る
1. プロジェクトの設定（歯車）→「マイアプリ」→ ウェブアプリ（`</>`）を追加。
2. 表示される `firebaseConfig` の値を、`js/firebase-config.js` の `YOUR_...` 部分に貼り付けます。
   - この値は秘密情報ではなく、公開しても問題ありません（不正な書き込みはルールで制限します）。
3. 変更したファイルをGitHubにコミットすれば反映されます。

### 4. 管理者アカウントを作る（ランキングの削除・名前変更に必要）
1. Firebaseコンソール →「構築」→「Authentication」→「始める」。
2. 「Sign-in method」タブで **「メール/パスワード」を有効**にします（「メールリンク」は不要）。
3. 「Users」タブ →「ユーザーを追加」で、次の内容を入力します。
   - メール：`admin@gomi-quiz.example.com`（実在のメールでなくて構いません）
   - パスワード：`gomi-0104`
4. 管理者画面で入力するパスワードは `0104` ですが、Firebaseは6文字以上を求めるため、内部で先頭に `gomi-` を付けて送っています。**Firebase側には必ず `gomi-0104` と登録**してください。
5. （推奨）「Settings」→「User actions」で「ユーザーの作成（登録）を有効にする」をオフにすると、第三者がアカウントを作れなくなります。

### 5. 動作確認
- クイズを最後まで解き、結果画面で名前を入れて「修了証を発行」→ `board.html` に表示されれば成功です。
- `admin.html` を開いてパスワード `0104` を入力し、「ランキング・獲得者の管理」に一覧が出れば管理機能も成功です。

### 仕組み
- **連続正解ランキング**：1回の挑戦中の「最大連続正解数」を記録します。同じ連続数なら早く達成した人が上位です。
- **修了証の獲得者**：合格ライン（管理者画面で設定）を超えて修了証を発行した人を新着順に表示します。
- 結果画面の「名前を公開する」にチェックが入っている場合のみ保存されます。ニックネームの利用をおすすめする注記を表示しています。
- 修了証は合格した場合のみ発行できます。不合格でも、連続正解が1以上ならランキングにだけ登録できます。

### 運用上の注意
- **不適切な名前の削除・名前の変更**：`admin.html` にログインし、「ランキング・獲得者の管理」から行えます（下の「管理者ページのパスワード」参照）。
- **なりすまし・不正の限界**：サーバーを持たない静的サイトなので、技術に詳しい人が自分で不正な数値を送ることは完全には防げません（ルールで「正解数は問題数以内」「連続数は問題数以内」などの範囲は制限しています）。学校・地域イベントなど身内での利用を想定した作りです。厳密な運用が必要な場合は、Cloud Functionsなどサーバー側での検証を追加してください。
- **個人情報**：名前はインターネット上に公開されます。児童・生徒が利用する場合は、ニックネームを使うよう案内してください。
- **無料枠**：Sparkプランの無料枠（読み取り 1日5万回など）の範囲で、小〜中規模のイベントなら十分運用できます。

## 管理者ページのパスワード

`admin.html` を開くとパスワード画面が出ます。初期パスワードは **`0104`** です。

### ランキング・獲得者の管理
パスワードを入力すると、管理者画面に「ランキング・獲得者の管理」が表示されます。
- **名前を変更**：その行の名前を書き換えて「保存」（Enterキーでも保存、Escキーで取り消し）。
- **削除**：確認のあと、その記録を削除します（元に戻せません）。
- **同じ名前の記録をまとめて変更・削除する**にチェックを入れると、連続正解ランキングと獲得者一覧の両方で、同じ名前の記録がすべて対象になります。同じ人が複数の記録を持っているときに便利です。
- 変更できるのは名前だけです。点数や日付は変更できません。

### 2段構えの守り（必ずお読みください）
GitHub Pagesはサーバーを持たない静的サイトで、ページのコードは誰でも読めます。そのため、守りは2段に分かれています。

1. **パスワード画面（見た目の入口）**：管理画面を普通の利用者に見せないための入口です。コードを読める人には回避できるため、これだけでは本当の防御になりません。問題の編集は、書き出した `questions.json` をGitHubに反映しない限りサイトに影響しないので、この段が破られても被害は限定的です。
2. **Firebaseのログインとルール（本当の防御）**：ランキングの削除・名前変更は、管理者アカウントでログインしたときだけ、Firebase側が許可します。パスワード画面を回避しても、このログインに成功しない限り、ランキングは変更できません。

### パスワードの強さについて
`0104` は4桁の数字なので、推測されやすいパスワードです。Firebaseは試行回数が多いと一時的にログインを止める仕組みを持っていますが、4桁ではそれでも十分に強いとは言えません。ランキングを不特定多数に公開する場合は、**英数字8文字以上など、より長いパスワードへの変更をおすすめします**。

### パスワードを変更する方法
1. 管理者画面を開き、ブラウザの開発者ツール（F12キー）の「コンソール」で `GomiAdminHash("新しいパスワード")` と入力して実行します。数字が表示されます。
2. `js/admin-gate.js` の `ADMIN_GATE_HASH` の値を、その数字に書き換えます。
3. Firebase Authentication の管理者ユーザーのパスワードを、**`gomi-` ＋ 新しいパスワード**に変更します（Usersタブ → ユーザーのメニュー → パスワードをリセット、または削除して作り直し）。
4. 変更したファイルをGitHubにコミットします。

### うまくいかないとき
- 「管理者アカウントでログインできません」と出る：手順「4. 管理者アカウントを作る」のメール・パスワード（`gomi-0104`）が正しいか確認してください。
- 「権限がありません」と出る：`firestore.rules` の最新版をFirebaseコンソールに貼って「公開」したか確認してください。
- パスワード画面は通るのにランキングが出ない：Firebaseの設定（`js/firebase-config.js`）が `YOUR_...` のままの可能性があります。問題の編集はFirebaseなしでも使えます。
